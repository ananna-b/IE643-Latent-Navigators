# Recorded numerical results

- `classification/`: original exported tables from the ResNet-50 experiment.
- `earlier_detection/`: exported tables for original YOLOv8n baseline/combined comparisons.
- `novelty/`: actual matched-arm tuning, selected checkpoint metadata, full held-out metrics and error diagnostics.

These are historical experiment outputs, **not rerun during packaging**. Some checkpoint fields contain absolute original Colab paths, which are provenance strings, not locally usable checkpoint files.
