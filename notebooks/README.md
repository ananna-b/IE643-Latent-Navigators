# Notebooks

These are the original research notebooks with executable code and markdown preserved. For a GitHub-friendly upload, embedded notebook outputs and execution counters were removed; numeric results and exported visuals are retained in `../results` and `../figures`.

- `01_classification_and_detection.ipynb`: imbalanced PASCAL VOC, ResNet-50 classification, original YOLO detection, synthetic and real shifts.
- `02_novelty_clean_anchored_yolov8n.ipynb`: latest available corrected v2 of the clean-anchored, minority-aware, low-light YOLO novelty experiment.

Run sequentially in Colab with suitable GPU/data/checkpoints as documented in the repository README.
